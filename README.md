# Instagram Exact Post Date (KST)

## 한국어

인스타그램 웹의 `329주`, `48주` 같은 상대 날짜를 한국 시간 기준 `YYYY.MM.DD`로 표시합니다. 날짜에 마우스를 올리면 게시 시각을 확인할 수 있습니다.

### 사용법

1. [Tampermonkey](https://www.tampermonkey.net/)를 설치합니다.
2. 브라우저 확장 관리 → Tampermonkey에서 **사용자 스크립트 허용**을 켭니다. 항목이 없으면 [공식 안내](https://www.tampermonkey.net/faq.php#Q209)를 확인하세요.
3. **[스크립트 설치](https://raw.githubusercontent.com/maniac428/instagram-exact-date/main/instagram-exact-date.user.js)**를 열고 **설치**를 누릅니다.
4. 인스타그램을 새로고침합니다.

코드만 열리면 Tampermonkey → 새 스크립트 만들기에 코드를 붙여넣고 `Ctrl+S`로 저장하세요.

원본 게시 시각이 있는 날짜에만 적용됩니다. 모든 날짜와 시각은 한국 시간(KST) 기준입니다.

## English

Replaces relative dates such as `329w` and `48w` on Instagram's website with `YYYY.MM.DD` in Korean Standard Time (KST). Hover over a date to see the posting time.

### Usage

1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. In your browser's extension settings, enable **Allow User Scripts** for Tampermonkey. If the option is missing, see the [official guide](https://www.tampermonkey.net/faq.php#Q209).
3. Open **[Install script](https://raw.githubusercontent.com/maniac428/instagram-exact-date/main/instagram-exact-date.user.js)** and click **Install**.
4. Refresh Instagram.

If the link only displays code, paste it into Tampermonkey → Create a new script and press `Ctrl+S` to save.

Only dates with an original timestamp are supported. All dates and times use KST (Asia/Seoul).
